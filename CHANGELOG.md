# Changelog

## [1.0.0] - 2026-08-02

### Added
- Initial release of TD Music Player
- Modern dark UI with customtkinter
- Dynamic theming from album art
- SQLite database for library management
- Real-time audio visualizer
- Lyrics viewer with LRC support
- Sleep timer and playback speed control
- System tray integration
- Keyboard shortcuts
- Auto-generated UI icons
- Playlist favorites and history
- Statistics dashboard
- Drag & drop support
